Human or AI or Both

AI detection that explains its reasoning. Determine if content is human-written, AI-generated, or a collaboration.

About Human or AI or Both

Human or AI or Both is a free, serverless AI detection tool that analyzes text to determine whether it was written by a human, generated by AI, or created through human-AI collaboration. Unlike simple binary classifiers, this tool provides detailed explanations of its reasoning and highlights specific passages that exhibit AI or human characteristics.

Important limitations

AI detection cannot be exact. This tool provides probability estimates and pattern analysis, not definitive proof. No AI detector can achieve 100% accuracy because:

  • Humans can write in ways that appear AI-like (formal, structured, repetitive)
  • AI can be prompted to write in human-like styles with intentional imperfections
  • Collaborative content blends both characteristics
  • Writing style varies enormously across individuals, languages, and contexts

Use this tool as one input among many when evaluating content authenticity. The analysis is most useful for understanding why content exhibits certain patterns, not for definitive authorship claims.

Two-stage analysis

This tool uses a two-stage detection system for improved accuracy:

  1. Local pattern detection (Slop Detector) — Fast heuristic-based analysis that scans for known AI writing patterns like formulaic transitions, antithetical constructions, AI vocabulary clusters, em dash overuse, and more. Also detects human markers like informal language, personal anecdotes, and self-corrections.
  2. Semantic analysis (LLM) — Deep analysis using AI to understand context, meaning, and subtle patterns that heuristics might miss. The local analysis results guide the semantic analysis for better calibration.

AI patterns detected (slop indicators)

The local detector scans for research-backed AI writing patterns including:

  • Critical: Antithetical constructions ("It's not about X, it's about Y"), sycophantic openings ("Great question!"), colon declarations, AI self-references
  • High: Formulaic transitions (However, Moreover, Furthermore), formulaic openers/closers, em dash overuse, pseudo-profound statements
  • Medium: Intensifier clusters (incredibly, extremely), hedge words, AI vocabulary (landscape, ecosystem, leverage), balanced perspectives, passive voice

Human markers detected

  • Informal language (gonna, wanna, btw, lol)
  • Personal anecdotes and specific details
  • Genuine uncertainty expressions
  • Colloquialisms and emotional authenticity
  • Self-corrections and tangents

What you get

Each analysis returns a Detection Score (0-100, where 0 = definitely human and 100 = definitely AI), a classification (Human, AI, or Collaboration), confidence level, detailed reasoning across multiple detection dimensions, highlighted passages with explanations, and the option to create cryptographic attestations via attest.ink.

Creating attestations

After analyzing content, you can create a cryptographic attestation that records the AI/human breakdown. This attestation:

  • Records the detection score and classification
  • Can be independently verified via attest.ink
  • Generates embeddable verification badges
  • Provides a shareable verification link

Email headers

Click "Copy Email Header" to generate a formatted text block suitable for prepending to emails or newsletters, showing the AI/human analysis breakdown.

Programmatic API

Use the tool programmatically via JavaScript:

  • window.whodoneitAnalyze(content, options) — Full analysis (returns Promise)
  • window.whodoneitEmailHeader(content) — Generate email header (synchronous, local only)

Options for whodoneitAnalyze:

  • quick: true — Use local heuristics only (fast, no API call)
  • apiMode: 'puter'|'openrouter'|etc — Select API provider

URL parameters

The tool supports URL parameters for automation and sharing:

  • ?content=your text here — Prefill the content input with text
  • ?url=https://example.com/article — Fetch content from a URL on page load
  • &enter — Add this to auto-analyze after loading content

API providers

Puter GPT-OSS is the default and is completely free with no API key required. OpenRouter is recommended for users who want access to hundreds of models through a single API key (CORS-friendly). Anthropic, OpenAI, Google Gemini, and Ollama are also supported.

All processing happens through the selected API provider. No data is stored on any server. Local analysis runs entirely in your browser.

Running Human or AI or Both with Ollama

Ollama lets you run AI models locally on your own machine. No API key needed, no data leaves your computer, and it's completely free.

Browser requirement: When using Ollama from GitHub Pages (or any HTTPS URL), Google Chrome is required. Safari and other WebKit browsers block HTTPS pages from connecting to local HTTP servers.

1. Install Ollama

curl -fsSL https://ollama.com/install.sh | sh

2. Pull the default model

ollama pull gpt-oss:20b

3. Start Ollama with remote access enabled

pkill ollama
OLLAMA_ORIGINS=* ollama serve

To make this permanent, add to your ~/.zshrc:

export OLLAMA_ORIGINS=*
