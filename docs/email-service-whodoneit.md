# Email Analysis Service Design

## Overview

Create an email forwarding service that analyzes emails for AI-generated content. Users forward suspicious emails to a special address and receive an automated reply with detection results.

## Architecture

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  User forwards  │────▶│  Email Service   │────▶│  Vercel Edge    │
│  email to       │     │  (Postmark/      │     │  Function       │
│  analyze@...    │     │   SendGrid)      │     │  /api/analyze   │
└─────────────────┘     └──────────────────┘     └────────┬────────┘
                                                          │
                        ┌──────────────────┐              │
                        │  Analysis Engine │◀─────────────┘
                        │  - Slop Detector │
                        │  - LLM (optional)│
                        └────────┬─────────┘
                                 │
                        ┌────────▼─────────┐
                        │  Send Reply via  │
                        │  Email Service   │
                        └──────────────────┘
```

## Components

### 1. Email Receiving (Postmark Inbound)

**Why Postmark?**
- Free tier includes inbound parsing
- Simple webhook-based delivery
- Good documentation
- Reliable delivery for replies

**Setup:**
1. Create Postmark account at postmarkapp.com
2. Set up Inbound Domain (e.g., `analyze.whodoneit.io` or use their free inbound address)
3. Configure webhook to point to your Vercel function

### 2. Vercel Edge Function

**Endpoint:** `POST /api/analyze-email`

```typescript
// api/analyze-email.ts
import { SlopDetector } from '../lib/slopDetector';

interface PostmarkInbound {
  From: string;
  FromName: string;
  To: string;
  Subject: string;
  TextBody: string;
  HtmlBody: string;
  StrippedTextReply: string;
  MessageID: string;
}

export default async function handler(req: Request) {
  if (req.method !== 'POST') {
    return new Response('Method not allowed', { status: 405 });
  }

  const email: PostmarkInbound = await req.json();
  
  // Extract content to analyze (use stripped reply to get just the forwarded content)
  const content = email.StrippedTextReply || email.TextBody;
  
  if (!content || content.length < 50) {
    return sendReply(email.From, email.Subject, {
      error: 'Content too short for meaningful analysis'
    });
  }

  // Run local slop detection
  const slopAnalysis = SlopDetector.analyze(content);
  
  // Optionally enhance with LLM (costs money per request)
  let fullAnalysis = null;
  if (process.env.ENABLE_LLM_ANALYSIS === 'true') {
    fullAnalysis = await runLLMAnalysis(content, slopAnalysis);
  }

  // Send reply
  await sendReply(email.From, email.Subject, {
    slopAnalysis,
    fullAnalysis,
    content: content.substring(0, 200) + '...'
  });

  return new Response('OK', { status: 200 });
}
```

### Step 3: Create the API Endpoint

Create `api/analyze-email.ts`:

```typescript
import type { VercelRequest, VercelResponse } from '@vercel/node';

// Import slop detector patterns and logic
import { analyze, classify } from '../lib/slopDetector';

// Postmark inbound email format
interface PostmarkInbound {
  From: string;
  FromName: string;
  To: string;
  Subject: string;
  TextBody: string;
  HtmlBody: string;
  StrippedTextReply: string;
  MessageID: string;
  Date: string;
}

interface AnalysisResult {
  score: number;
  classification: string;
  confidence: string;
  human_probability: number;
  ai_probability: number;
  summary: string;
  ai_patterns: Array<{ type: string; count: number; examples: string }>;
  human_markers: Array<{ type: string; count: number; examples: string }>;
}

export default async function handler(
  req: VercelRequest,
  res: VercelResponse
) {
  // Verify Postmark webhook (optional security)
  const authToken = req.headers['x-postmark-token'];
  if (process.env.POSTMARK_WEBHOOK_TOKEN && authToken !== process.env.POSTMARK_WEBHOOK_TOKEN) {
    return res.status(401).json({ error: 'Unauthorized' });
  }

  if (req.method !== 'POST') {
    return res.status(405).json({ error: 'Method not allowed' });
  }

  try {
    const email: PostmarkInbound = req.body;
    
    // Extract the forwarded content
    // StrippedTextReply removes the reply chain, leaving just forwarded content
    const content = extractForwardedContent(email);
    
    if (!content || content.length < 50) {
      await sendReply(email.From, email.Subject, 'Content too short for analysis (minimum 50 characters).');
      return res.status(200).json({ status: 'replied', error: 'too_short' });
    }

    // Run analysis
    const analysis = analyze(content);
    const classification = classify(analysis.score);
    
    const result: AnalysisResult = {
      score: analysis.score,
      classification,
      confidence: analysis.confidence,
      human_probability: 100 - analysis.score,
      ai_probability: analysis.score,
      summary: analysis.explanation,
      ai_patterns: analysis.indicators.ai.slice(0, 10),
      human_markers: analysis.indicators.human.slice(0, 5)
    };

    // Send reply email
    await sendReply(email.From, email.Subject, formatReport(result, content));
    
    return res.status(200).json({ status: 'analyzed', result });
  } catch (error) {
    console.error('Analysis error:', error);
    return res.status(500).json({ error: 'Internal server error' });
  }
}

function extractForwardedContent(email: PostmarkInbound): string {
  // Try stripped reply first (removes previous email chain)
  if (email.StrippedTextReply && email.StrippedTextReply.length > 50) {
    return email.StrippedTextReply;
  }
  
  // Fall back to full text body
  let content = email.TextBody || '';
  
  // Try to extract forwarded message content
  const forwardMarkers = [
    /---------- Forwarded message ---------/i,
    /-------- Original Message --------/i,
    /Begin forwarded message:/i,
    /From:.*\nTo:.*\nDate:.*\nSubject:/im
  ];
  
  for (const marker of forwardMarkers) {
    const match = content.match(marker);
    if (match && match.index !== undefined) {
      // Get content after the forward header
      const afterHeader = content.slice(match.index + match[0].length);
      // Skip the header lines and get the body
      const lines = afterHeader.split('\n');
      let bodyStart = 0;
      for (let i = 0; i < lines.length && i < 10; i++) {
        if (lines[i].trim() === '') {
          bodyStart = i + 1;
          break;
        }
      }
      return lines.slice(bodyStart).join('\n').trim();
    }
  }
  
  return content;
}

function formatReport(result: AnalysisResult, content: string): string {
  const contentPreview = content.substring(0, 150).replace(/\n/g, ' ') + '...';
  
  let report = `
═══════════════════════════════════════════════════════
              WHODONEIT AI DETECTION REPORT
═══════════════════════════════════════════════════════

Classification: ${result.classification.toUpperCase()}
Detection Score: ${result.score}/100 (0=human, 100=AI)
Confidence: ${result.confidence.toUpperCase()}

───────────────────────────────────────────────────────
                    BREAKDOWN
───────────────────────────────────────────────────────

Human Probability: ${result.human_probability}%
AI Probability: ${result.ai_probability}%

───────────────────────────────────────────────────────
                  AI PATTERNS FOUND
───────────────────────────────────────────────────────
`;

  if (result.ai_patterns.length > 0) {
    for (const pattern of result.ai_patterns) {
      report += `• ${pattern.type} (${pattern.count}x)\n`;
      if (pattern.examples) {
        report += `  "${pattern.examples.substring(0, 60)}..."\n`;
      }
    }
  } else {
    report += '(No significant AI patterns detected)\n';
  }

  report += `
───────────────────────────────────────────────────────
                 HUMAN MARKERS FOUND
───────────────────────────────────────────────────────
`;

  if (result.human_markers.length > 0) {
    for (const marker of result.human_markers) {
      report += `• ${marker.type} (${marker.count}x)\n`;
    }
  } else {
    report += '(No significant human markers detected)\n';
  }

  report += `
───────────────────────────────────────────────────────
                    SUMMARY
───────────────────────────────────────────────────────

${result.summary}

───────────────────────────────────────────────────────
                 CONTENT ANALYZED
───────────────────────────────────────────────────────

"${contentPreview}"

═══════════════════════════════════════════════════════
This analysis was generated by whodoneit
https://97115104.github.io/whodoneit

DISCLAIMER: AI detection cannot be 100% accurate.
Use as one input among many when evaluating authenticity.
═══════════════════════════════════════════════════════
`;

  return report;
}

async function sendReply(to: string, originalSubject: string, body: string): Promise<void> {
  const postmarkToken = process.env.POSTMARK_SERVER_TOKEN;
  if (!postmarkToken) {
    throw new Error('POSTMARK_SERVER_TOKEN not configured');
  }

  const response = await fetch('https://api.postmarkapp.com/email', {
    method: 'POST',
    headers: {
      'Accept': 'application/json',
      'Content-Type': 'application/json',
      'X-Postmark-Server-Token': postmarkToken
    },
    body: JSON.stringify({
      From: process.env.FROM_EMAIL || 'analyze@whodoneit.io',
      To: to,
      Subject: `Re: ${originalSubject} — AI Detection Analysis`,
      TextBody: body,
      MessageStream: 'outbound'
    })
  });

  if (!response.ok) {
    const error = await response.text();
    throw new Error(`Postmark error: ${error}`);
  }
}
```

### Step 4: Set Up Postmark

1. **Create Account:** Sign up at postmarkapp.com

2. **Create Server:** 
   - Go to Servers → Add Server
   - Name it "whodoneit-email"

3. **Configure Inbound:**
   - Go to your server → Inbound
   - Note your inbound address (e.g., `abc123@inbound.postmarkapp.com`)
   - Or set up custom domain (recommended): `analyze@whodoneit.io`
   - Set webhook URL: `https://your-vercel-project.vercel.app/api/analyze-email`

4. **Get API Token:**
   - Go to Server → API Tokens
   - Copy the Server API Token

5. **Configure Vercel Environment:**
   ```bash
   vercel env add POSTMARK_SERVER_TOKEN
   vercel env add FROM_EMAIL
   vercel env add POSTMARK_WEBHOOK_TOKEN  # Optional security
   ```

### Step 5: Deploy to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Login and deploy
vercel login
vercel

# For production
vercel --prod
```

### Step 6: Set Up Custom Domain (Optional)

For `analyze@yourdomain.com`:

1. **DNS Setup:**
   - Add MX record pointing to Postmark: `10 inbound.postmarkapp.com`
   
2. **Postmark Domain Verification:**
   - Add required TXT records for SPF/DKIM
   - Verify domain in Postmark dashboard

3. **Configure From Address:**
   - Set up Sender Signature in Postmark for reply emails

## Security Considerations

1. **Webhook Verification:** Use Postmark's webhook token for authenticity
2. **Rate Limiting:** Add rate limiting to prevent abuse
3. **Content Filtering:** Validate content size limits
4. **Reply-To Validation:** Only reply to valid email addresses
5. **Error Handling:** Don't expose internal errors in replies

## Usage Instructions for End Users

1. **To analyze an email:**
   - Forward the suspicious email to `analyze@whodoneit.io`
   - Wait 10-30 seconds for the reply

2. **For best results:**
   - Forward the original email (don't copy-paste)
   - Include the full email body
   - Works with newsletters, messages, articles

3. **Limitations:**
   - Minimum 50 characters required
   - Text content only (images not analyzed)
   - Results are probabilistic, not definitive
